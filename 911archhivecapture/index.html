Privacy and platform limits

A GitHub Pages app cannot access Facebook, Instagram, LinkedIn or other sites’ cookies, nor reliably display those sites in an embedded panel. Open the source in a normal tab, use the extension on pages where you are signed in, and archive only material you are allowed to preserve.

DESIGNED FOR REAL-WORLD WEB PAGES

What this app can — and cannot — do

It can

  • Save a local, searchable catalog in IndexedDB.
  • Store source links, notes, dates, tags, media URLs and local image attachments.
  • Parse metadata you paste or import from the extension.
  • Export portable JSON and optionally write that catalog to your GitHub repository.

It cannot

  • Read, copy or retain the cookies from social networks.
  • Bypass sign-in, paywalls, CORS, copyright, download restrictions or a site’s embed policy.
  • Guarantee an external source remains live or allows hotlinked media.
  • Use GitHub Pages as private file storage.

For a logged-in social page, the extension can inspect the rendered page in your own browser. Review what it captures before importing it.
